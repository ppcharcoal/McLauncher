McLauncher 0.7.0

- **Back to McLauncher**, with a new icon in the same family as Aurora: a rounded tile with a grass-to-sky gradient and a flat white block. If you installed 0.6.0 ("Cairn"), this package replaces it; your instances and settings stay.
- **Animations** (on by default, Settings → Appearance): pages glide in and out, instance tabs slide with an underline that follows you, mod lists and search results ease in, loading shows shimmering placeholders, dialogs and the project drawer spring open and close, toasts slide, and switching styles crossfades the colours. Turning a mod on or off and deleting one now happen in place without reloading the list.
- **Frutiger Aero** now uses a real Aero wallpaper (sky, bubbles, paper cranes) with glossy buttons, a glossy glass tab bar and glass cards. No more blurred picture behind the instance header.
- **Dark Matter**: the sidebar now fades smoothly into the starfield instead of ending in a glowing line.
- Opening a modpack's Mods tab no longer re-checks its files every time: unknown files are looked up once, quietly. Use "Check modpack files" in the instance menu when you want a full check.

Install: see the README for Arch Linux and Windows instructions.
