McLauncher 0.3.0

- **Forge and NeoForge support**: pick Fabric, Forge, NeoForge or Vanilla when making an instance, with the exact loader version (Forge's recommended build is preselected). Covers every Forge release from 1.7.10 up to the newest, including old 1.12.2-era Forge, and every NeoForge release.
- **Mods and modpacks for every loader**: Discover shows mods for the instance's loader on Modrinth and CurseForge (NeoForge 1.20.1 also gets Forge mods). Modpacks can be filtered by loader, and Forge/NeoForge `.mrpack`, CurseForge and Prism packs install directly.
- **Shader packs on Forge** bring Oculus along automatically; on Fabric and NeoForge, Iris.
- The mods list reads names, versions and icons from Forge and NeoForge mods too.
- Exports keep the right loader, so a Forge pack exported to `.mrpack` re-imports as Forge.

Install: see the README for Arch Linux and Windows instructions.
